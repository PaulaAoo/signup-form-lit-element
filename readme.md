# Formulario de Registro con Lit Element
   
   Proyecto desarrollado para el Módulo 3 -  webcomponents con Lit Element
   
   ## Descripción
   Formulario de registro completo con validación en tiempo real, construido con Lit Element y componentes web.
   
   ## Tecnologías
   - Lit Element 3.x
   - Vite
   - JavaScript ES6+
   - CSS3
   
   ##  Instalación
```bash
   npm install
   npm run dev
```
   
   ## Estructura de Componentes
   - `signup-app.js` - Componente principal (layout)
   - `signup-form.js` - Formulario con validación
   - `form-input.js` - Input reutilizable
   - `submit-button.js` - Botón con estados
   - `info-section.js` - Sección informativa
